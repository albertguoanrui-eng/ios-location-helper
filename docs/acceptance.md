# 验收记录

日期：2026-09-11。

## 已通过的本地校验

- 默认关闭、损坏存储回退、开关跨脚本实例持久化。
- 经纬度范围与有限数值、整数精度、严格布尔配置。
- 本机 HTML / JSON 接口、跨域修改拒绝、异常输入与存储失败。
- 5 个精确域名与 WLOC 路径匹配，不命中相似恶意域名或其他路径。
- 合成 protobuf 中 Wi-Fi、22/24 基站位置写入伦敦，负经度正确；保留无关字段。
- 合成 ARPC、prefixed 和裸 protobuf 响应封装处理。
- 没有坐标的容器不误报成功；压缩、空、异常状态和无效响应保持原样。
- 变更坐标后诊断更新、停止后不改写新响应、导出诊断脱敏。
- 在 Node VM 中执行实际打包的三份 Shadowrocket 脚本，共享模拟存储，覆盖设置 → 请求 → 响应 → 查询 → 停止。

共 29 项 Node 自动测试。测试正文为合成数据，不是从用户 iPhone 抓取的流量；VM 不是 Shadowrocket 真机运行时。

构建校验还检查脚本与页面 JavaScript 语法、产物 SHA-256、ZIP 完整性及打包源码与工作区一致性。本地 HTTP 下载另行检查预览页、模块、脚本和源码 ZIP，并拒绝非产物路径。

## 0.1.2 新增验证

- 在模拟 DOM 中执行实际面板脚本，读取与截图相同结构的 waiting 状态，无自动 Fetch 查询。
- 保存及停止各发送一次 POST，重新导航后从存储读取对应状态。
- 原生 Node HTTP 服务与 Fetch 验证连续整页读取关闭、开启、关闭状态；响应禁止缓存。
- 嵌入 JSON 的 HTML 分隔符及字符串替换符安全转义，解析后保持原数据。
- 无快照、协议类型错误、配置字段错误、未知阶段及无有效计数的 patched 状态均禁用控制，并提示具体字段。
- 校验失败可复制脱敏连接诊断并整页刷新；浏览器恢复缓存页面时重新导航。
- 修改请求的 HTTP 错误、缺失标识、非 JSON、HTTP 200 错误正文和网络失败不自动重试、不显示保存成功。
- HTTP 页面阻止控制请求并提示 HTTPS；模块使用新的版本化脚本地址。

0.1.1 用户反馈持续不兼容，但直接状态接口返回合法 JSON；该差异尚未在真实 Safari / Shadowrocket 网络栈复现。0.1.2 调整读取路径，不能据本地通过宣称手机端已经修复。
